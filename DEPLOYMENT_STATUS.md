# Deployment status

This package includes Vercel SPA configuration for the React frontend and a documented deployment path for the Spring Boot API and PostgreSQL database.

No cloud resources have been created and no public URL has been deployed from this environment. The project owner must connect their GitHub, Vercel, Render and Neon accounts and supply their own credentials.

The current codebase is an MVP/demo foundation, not a fully production-secured enterprise system. See `deployment/DEPLOY_TO_VERCEL_AND_RENDER.md` for the exact limitations and deployment steps.
